# Alarm Manager 🚨

Модуль для централизованного управления тревогами в скриптах СИАМ.
Позволяет регистрировать тревоги разных классов, настраивать задержки, способы квитирования и визуальное отображение.

![Version](img/versions/AlarmManager-v1-green.svg)
![SIAM](img/versions/SIAM-1.1.15.2-green.svg)

## 📦 Возможности

- ✅ Регистрация тревог трёх классов: `ERROR`, `WARN`, `INFO`
- ✅ Поддержка разных способов наблюдения: событие, дискретный канал, аналоговый канал, изменение, клиент Кодесис
- ✅ Настраиваемые задержки активации (`delay_on`) и деактивации (`delay_off`)
- ✅ Несколько методов квитирования: `REP`, `REP_ACK`
- ✅ Визуальные эффекты появления: статичный, мигание, вспышка
- ✅ Автоматическое создание каналов количества активных/неквитированных тревог
- ✅ Поддержка нескольких таблиц тревог с независимыми настройками

## 🚀 Быстрый старт

```lua
local am = require("meralualib.alarm_manager")

-- Создаём таблицу тревог
local atable = am.Atable:new()
atable.table_id = 1  -- Номер таблицы в СИАМ.

function lua_main()
    am:upd()  -- Вызываем циклическое обновление Менеджера Тревог в начале скрипта.

    -- Регистрируем тревогу 1.
    local alarm = atable:alarm()
    alarm.logic = am.LOGIC.EVENT,
    alarm.event = getValue("my_signal") > 42,
    alarm.class = am.ALARM_CLASS.ERROR,
    alarm.msg = "Авария: превышение сигнала",
    alarm.confirm_method = am.CONFIRM_METHOD.REP_ACK,
    alarm.delay_on = 1,  -- задержка активации 1 секунда

    -- Регистрируем тревогу 2.
    alarm = atable:alarm()
    alarm.event = getValue("not_my_signal") < 300,
    alarm.class = am.ALARM_CLASS.WARN,
    alarm.msg = "Предупреждение: сигнал ниже предварительного предела",

end
```

## ⚙️ Установка

Модуль подключается через `require`:
```lua
local am = require("meralualib.alarm_manager")
```

## 📖 API

### `am.Atable:new(conf?)` → `M.Atable`

Создаёт экземпляр таблицы тревог.

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `table_id` | integer | `-1` | Номер таблицы в СИАМ |
| `module_name` | string | `""` | Имя системы для комментариев каналов |
| `display_id_at_msg` | boolean | `false` | Показывать внутренний ID в сообщении |
| `display_alarm_state_label` | boolean | `true` | Показывать лейбл состояния тревоги |
| `analog` | table | — | Настройки для аналоговых тревог |

### `atable:alarm(args)` → `AlarmManager.AlarmArgs`

Регистрирует тревогу в таблице.

> ⚠️ **Важно:** вызов `atable:alarm{}` нельзя помещать внутрь `if` — это может привести к остановке скрипта в рантайме при проверке параметров.

### `am:upd()`

Циклическое обновление менеджера. Должна вызываться **один раз** в `lua_main()` **до** регистрации тревог.

## 🔢 Перечислители

### `am.LOGIC` — способ наблюдения

| Значение | Описание |
|----------|----------|
| `EVENT` | Событие `true`/`false` или число >0/0|
| `DISCRETE` | Дискретный канал |
| `ANALOG` | Аналоговый канал с уставками |
| `CHANGE` | Любое изменение события |
| `CS_CLIENT` | Повторение состояния из Кодесис |

### `am.ALARM_CLASS` — класс тревоги

| Значение | Описание |
|----------|----------|
| `ERROR` | Авария (красный) |
| `WARN` | Предупреждение (оранжевый) |
| `INFO` | Информирование (жёлтый) |

### `am.CONFIRM_METHOD` — способ квитирования

| Значение | Описание |
|----------|----------|
| `REP` | Деактивация |
| `REP_ACK` | Подтверждение деактивированной |

### `am.ALARM_APPEARANCE` — визуальный эффект

| Значение | Описание |
|----------|----------|
| `STATIC` | Тревога появляется сразу |
| `BLINK` | Мигание при появлении |
| `FLASH` | Вспышка при появлении |

## 📝 Примеры

### Тревога с задержкой активации

```lua
atable:alarm{
    logic = am.LOGIC.EVENT,
    event = getValue("signal") > 1,
    class = am.ALARM_CLASS.ERROR,
    msg = "Превышение сигнала",
    delay_on = 2,   -- сработает, если сигнал > 1 держится 2 секунды
    delay_off = 5,  -- сбросится через 5 секунд после возврата
}
```

### Аналоговая тревога с уставками

```lua
atable:alarm{
    logic = am.LOGIC.ANALOG,
    channel = "temperature",
    limit_type = am.LIMIT_TYPE.LOW_HIGH,
    low = 10,
    high = 80,
    hyst_low = 2,
    hyst_high = 2,
    class = am.ALARM_CLASS.WARN,
    msg = "Температура вне диапазона",
}
```

### Несколько таблиц тревог

```lua
local atable1 = am.Atable:new{ table_id = 1, module_name = "Система_01" }
local atable2 = am.Atable:new{ table_id = 2, module_name = "Система_02" }

function lua_main()
    am:upd()
    atable1:alarm{ ... }
    atable2:alarm{ ... }
end
```
