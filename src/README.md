Библиотека для Lua, предоставляющая набор модулей для разработки скриптов для СИАМ.

## Установка
- По пути `c:\Program Files (x86)\Mera\SIAM\` создать папку `meralualib`
- Скопировать в `c:\Program Files (x86)\Mera\SIAM\meralualib` папку с релизом MLL, например v1_0_0:
 ```
c:\Program Files (x86)\Mera\SIAM\meralualib\v1_0_0
```

## Настройка редактора кода VSCode для подсказок по MLL
- открыть VSCode
- установить расширение `Lua language Server coded by Lua` от `sumneko`
- в VSCode открыть папку со скриптами как проект: `File` -> `Open Folder` -> `D:\MDB\scripts` -> `Select Folder`
- создать папку `.vscode`, в папке создать файл `settings.json`
- в `settings.json` вставить:
```json
{

    "Lua.workspace.library": [
        // Путь до MLL для интеллектуальной подсказки в коде:
        "c:/Program Files (x86)/Mera/SIAM/",
    ],

    "Lua.diagnostics.enable": true,
    "Lua.completion.enable": true,
    "Lua.completion.workspaceWord": false,
    "Lua.completion.showWord": "Enable",
    "Lua.completion.callSnippet": "Replace",
    "Lua.completion.showParams": true,
    "Lua.completion.keywordSnippet": "Both",

}
```

## Импорт модулей библиотеки MLL
Пример импорта модуля менеджера тревог:
```lua
-- D:\MDB\scripts\test.lua
local am = require("meralualib.v1_0_0.alarm_manager")  -- Менеджер тревог.
```

## Список модулей
- **Abs** (документация в разработке)
- [**alarm_manager**](alarm_manager/README.md) - модуль для централизованного управления тревогами в скриптах СИАМ. Позволяет регистрировать тревоги разных классов, настраивать задержки, способы квитирования и визуальное отображение.
- **analog** (*документация в разработке*) - модуль обработки аналоговых сигналов.
- **bitsignals** (*документация в разработке*) - модуль обработки битовых сигналов.
- **collect** (*документация в разработке*) - модуль для работы с коллекциями (словари, списки, ...).
- **convertfunc** (*документация в разработке*) - модуль конвертации величин.
- **datatype** (*документация в разработке*) - модуль типов данных (перечислители, ...).
- **dbg** (*документация в разработке*) - модуль для отладки в IDE.
- **decorator** (*документация в разработке*) - модуль декораторов.
- **emulate** (*устаревший*) - модуль эмуляции lua API СИАМ.
- **file** (*документация в разработке*) - модуль работы с файлами.
- **generators** (*документация в разработке*) - модуль генераторов сигналов.
- **hmi** (*документация в разработке*) - модуль обработки элементов графического интерфейса мнемосхем СИАМ (кнопки, выпадающий список, ...).
- **maths** (*документация в разработке*) - математические функции.
- **module_utils** (*документация в разработке*) - работа с модулями.
- **nodes** (*документация в разработке*)
- **serializer** (*документация в разработке*)
- **siam_api** (*документация в разработке*) - модуль эмуляции lua API СИАМ для отладки в IDE.
- **siam_wrapper** (*документация в разработке*) - модуль обёрток СИАМ функций.
- **spec** (*документация в разработке*) - модуль специализировнных функций (кусочно-линейная интерполяция, ...).
- **tags** (*документация в разработке*)
- **timers** (*документация в разработке*) - модуль работы с таймерами (TON, TOF, ...).
- **utils** (*документация в разработке*)
