# MeraluaLib
Библиотека для Lua, предоставляющая набор утилит и функций для разработки скриптов для СИАМ.
## 📖 Документация
- [Версионирование](docs/VERSIONING.md) — правила именования версий.
- [Разработка](docs/DEV.md) — руководство для разработчиков (настройка окружения, сборка, тестирование).
## 🚀 Быстрый старт
### Установка
Склонируйте репозиторий:
```bash
git clone git@gl.mera.local:acs/meralualib.git
cd meralualib
```
### Сборка
Для сборки библиотеки выполните скрипт:
```bash
./build.sh
```
Собранные файлы появятся в папке `build/`.
## 🛠 Разработка
Если вы планируете вносить изменения в код, ознакомьтесь с [руководством по разработке](docs/DEV.md). Там описаны:
- Требования к окружению.
- Процесс сборки с использованием токенов.
- Правила оформления кода и коммитов.
